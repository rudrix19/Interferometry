# Interferometry

This repository contains notes, simulations, and project files developed during my Summer 2026 research project on interferometry and optical cavities. 
The project focuses on understanding the optical systems that underpin modern gravitational-wave observatories and precision measurement experiments.
This work was carried out as part of my Summer 2026 research project under the guidance of Dr. Deepak Pandey, IUCAA, Pune.
